## 📖 What is Rublex?
As a P2P trader working across different exchanges—often with multiple accounts on each—managing operations can quickly become a nightmare. Constantly swapping between tabs, browsers, and mobile apps to handle orders, update ads, and reply to chats is exhausting and prone to costly mistakes.

**Rublex Bot** is aimed at solving this. It centralizes your entire P2P workflow into a single environment running entirely inside Telegram. Powered by AI, it manages your ads, orders, and customer chats across multiple exchanges, saving you time and keeping your trading organized.

## 🔒 Security & API Integration
We take your security seriously. Rublex legally connects to your exchanges via their official API management systems.
* **Minimum Privileges Required:** The bot only requires basic trading and chat permissions. **No withdrawal permissions** are ever required.
* **Encrypted:** All API keys and sensitive data are strictly encrypted on our backend. You maintain full control over your assets.

## 🛠 Tech Stack
Rublex is built for speed, efficiency, and reliability using modern tooling:
* **[Golang](https://go.dev/)**: The core backend engine powering the bot.
* **[Pocketbase](https://pocketbase.io/)**: An open-source backend providing an embedded database with real-time capabilities.
* **[Gogram](https://github.com/amarnathcjd/gogram)**: MTProto library for native Telegram operations.
* **[Req](https://github.com/imroc/req)**: A powerful, easy-to-use HTTP client library for Go.
* **[SQLite](https://sqlite.org/)**: A lightweight, lightning-fast database.
